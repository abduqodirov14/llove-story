# 📼 llove-story | Analog Cinema Master (1994)

> **Adriano Celentano — "Ja Tebia Liubliu" (Quel Punto, 1994)**  
> 8D Audio, Dual Analog VU Meters, Anamorphic Lens Flare, and Smooth Kinetic Typography.

## ✨ Features
- 🎛️ **Dual Analog VU Meters:** Real-time audio-reactive stereo needles powered by the Web Audio API.
- 🎞️ **Vintage Reel-to-Reel Tape Spools:** Rotating magnetic tape wheels synchronized with playback.
- 🎬 **Anamorphic Lens Flare:** Optical horizontal light leaks on drops and kicks.
- 📜 **Monumental Kinetic Typography:** Slow, cinematic optical blur transitions (`Italiana` & `Playfair Display 900`).
- 🎧 **Night Music 8D Audio:** True multilingual retro love classic.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
